
# WalletWise 💰

WalletWise is a beginner-friendly demo wallet application built with Python, Streamlit, and SQLite.

## Features

- User registration and login
- Demo wallet balance
- Add demo money and send demo money
- Transaction history
- Money added vs. money sent chart
- Monthly spending chart
- Transaction type and date filters
- Export transactions to CSV

## Technologies Used

- Python
- Streamlit
- Pandas
- SQLite

## How to Run

1. Install Python.
2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Run the application:

   ```bash
   streamlit run app.py
   ```

## Important Notice

WalletWise is an educational demo project. It does not process real payments or store real money.
